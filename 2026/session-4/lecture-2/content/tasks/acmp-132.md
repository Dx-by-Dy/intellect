# Алгоритм Дейкстры

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (ACMP 132)](https://acmp.ru/index.asp?main=task&id_task=132){: target="_blank" rel="noopener" }

Лимит времени — 1 с, память — 16 МБ.

Дан ориентированный граф с неотрицательными весами. Найдите минимальный суммарный вес пути из вершины `S` в вершину `F`.

## Входные данные

В файле `INPUT.TXT` сначала записаны `N`, `S` и `F`, где `1 ≤ N ≤ 100` и `1 ≤ S, F ≤ N`.

Затем идут `N` строк по `N` целых чисел. Элемент в строке `i` и столбце `j` равен весу ребра из `i` в `j` или `-1`, если ребра нет. Веса лежат в диапазоне от 0 до 100. На главной диагонали стоят нули.

## Выходные данные

Запишите в `OUTPUT.TXT` минимальный суммарный вес пути. Если добраться из `S` в `F` невозможно, запишите `-1`.

## Пример

Ввод

```text
3 2 1
0 1 1
4 0 1
2 1 0
```

Вывод

```text
3
```

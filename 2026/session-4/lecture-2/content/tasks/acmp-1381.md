# Алгоритм Дейкстры — 2

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (ACMP 1381)](https://acmp.ru/asp/do/index.asp?id_course=2&id_problem=1037&id_section=32&id_topic=54&main=task)

Лимит времени — 1 с, память — 16 МБ.

В ориентированном графе с неотрицательными весами найдите один путь минимального суммарного веса из вершины `S` в вершину `F`.

## Входные данные

Первая строка файла `INPUT.TXT` содержит число вершин `N` и номера `S` и `F` (`1 ≤ N ≤ 100`, `1 ≤ S, F ≤ N`).

Далее записана матрица из `N` строк по `N` целых чисел. Для пары вершин `i` и `j` значение `-1` означает, что ребра из `i` в `j` нет. Значение от 0 до 100 задаёт вес этого ребра. Главная диагональ заполнена нулями.

## Выходные данные

Запишите в `OUTPUT.TXT` номера вершин любого кратчайшего пути в порядке обхода, начиная с `S` и заканчивая `F`. Если пути нет, запишите `-1`.

## Примеры

### Пример 1

Ввод

```text
3 2 1
0 1 1
4 0 1
2 1 0
```

Вывод

```text
2 3 1
```

### Пример 2

Ввод

```text
4 2 3
0 -1 -1 -1
1 0 -1 1
1 -1 0 1
-1 -1 -1 0
```

Вывод

```text
-1
```

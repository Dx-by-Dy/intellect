# Один шаг Дейкстры

[Все задачи](../problems/index.md)

Ввод и вывод через стандартные потоки. Лимит времени — 1 с.

На занятии класс тренируется выполнять отдельные шаги алгоритма Дейкстры. Для упражнения дана таблица с текущими оценками расстояний, предшественниками и отметками о том, какие вершины уже обработаны. У необработанной вершины оценка может быть числом или бесконечностью.

Выберите необработанную вершину с наименьшей конечной оценкой. При равенстве выберите меньший номер. Для каждой исходящей из неё дуги к необработанной вершине сравните прежнюю оценку с суммой оценки выбранной вершины и веса дуги. При строгом улучшении замените оценку и запишите выбранную вершину как предшественника. Бесконечная оценка больше любого числа. Если выбрать вершину невозможно, оценки и предшественники сохраняются.

## Входные данные

В первой строке даны целые числа `n` и `m` — число вершин и число дуг (`1 ≤ n ≤ 100 000`, `0 ≤ m ≤ 200 000`).

Во второй строке даны текущие оценки `d_1, …, d_n` (`-1 ≤ d_i ≤ 10¹⁵`). Значение `-1` обозначает бесконечность.

В третьей строке даны номера предшественников `p_1, …, p_n` (`0 ≤ p_i ≤ n`). Значение `0` означает, что предшественника нет. Если `d_i=-1`, то `p_i=0`.

В четвёртой строке даны числа `f_1, …, f_n`. Значение `1` означает, что вершина обработана, а `0` — что нет. У обработанной вершины оценка конечна.

В каждой из следующих `m` строк даны целые числа `a`, `b`, `w` — дуга из `a` в `b` веса `w` (`1 ≤ a,b ≤ n`, `a ≠ b`, `0 ≤ w ≤ 10⁹`). Возможны параллельные дуги.

## Выходные данные

В первой строке выведите номер выбранной вершины или `0`, если конечные оценки есть только у обработанных вершин либо все оценки бесконечны. Во второй строке выведите `n` оценок после шага. В третьей строке выведите `n` номеров предшественников после шага. В обеих строках выводите значения по порядку номеров вершин. Используйте `-1` для бесконечной оценки и `0` для отсутствующего предшественника.

## Примеры

### Пример 1

Ввод

```text
6 6
0 6 6 -1 9 6
0 1 1 0 1 1
1 0 0 0 0 0
2 4 4
2 4 1
2 5 1
2 6 0
3 4 0
4 6 0
```

Вывод

```text
2
0 6 6 7 7 6
0 1 1 2 2 1
```

### Пример 2

Ввод

```text
3 1
0 -1 7
0 0 1
1 0 1
1 2 0
```

Вывод

```text
0
0 -1 7
0 0 1
```

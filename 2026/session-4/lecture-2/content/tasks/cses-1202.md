# Статистика самых дешёвых маршрутов

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (CSES 1202)](https://cses.fi/problemset/task/1202)

Лимит времени — 1 с, память — 512 МБ.

Найдите минимальную стоимость перелёта из города `1` в город `n`. Среди маршрутов этой стоимости определите, сколько их всего и из какого наименьшего и наибольшего числа рейсов они состоят. До города `n` можно добраться.

## Входные данные

В первой строке записаны число городов `n` и число рейсов `m` (`1 ≤ n ≤ 10⁵`, `1 ≤ m ≤ 2 · 10⁵`).

Затем даны `m` строк вида `a b c`: односторонний рейс из города `a` в город `b` стоит `c` (`1 ≤ a, b ≤ n`, `1 ≤ c ≤ 10⁹`).

## Выходные данные

Выведите четыре целых числа в следующем порядке.

1. Минимальная стоимость поездки.
2. Число маршрутов этой стоимости по модулю `10⁹ + 7`.
3. Наименьшее число рейсов среди этих маршрутов.
4. Наибольшее число рейсов среди этих маршрутов.

## Пример

Ввод

```text
4 5
1 4 5
1 2 4
2 4 5
1 3 2
3 4 3
```

Вывод

```text
5 2 1 2
```

# Курьер и сроки

[Все задачи](../problems/index.md) · [Яндекс Контест · B](https://new.contest.yandex.ru/contests/104356/problems?id=7822306%2F2026_11_24%2FRHFSmg4BpU){: target="_blank" rel="noopener" }

Ввод и вывод через стандартные потоки. Лимит времени — 1 с.

Курьер доставляет документы в несколько пунктов по заранее заданному маршруту. В каждом пункте документы готовы принять до определённого момента включительно. Если курьер прибывает после этого момента, доставка в пункт считается просроченной.

Курьер выезжает в момент `0`, посещает контрольные точки в указанном порядке и сразу после прибытия продолжает поездку. Для каждого участка известно время в дороге. Найдите первую контрольную точку, в которую курьер опоздает.

## Входные данные

В первой строке дано целое число `n` (`1 ≤ n ≤ 200 000`). Точки пронумерованы от `1` до `n` в порядке посещения.

В каждой из следующих `n` строк даны целые числа `t_i` и `d_i` — длительность поездки до точки `i` с предыдущей позиции и срок прибытия в неё (`0 ≤ t_i ≤ 10⁹`, `0 ≤ d_i ≤ 2 · 10¹⁴`). Все времена даны в минутах.

## Выходные данные

Выведите номер первой точки, в которую курьер прибудет позже её срока. Если он везде успеет, выведите `0`.

## Примеры

### Пример 1

Ввод

```text
4
5 5
2 10
4 10
2 12
```

Вывод

```text
3
```

### Пример 2

Ввод

```text
3
0 0
3 3
0 3
```

Вывод

```text
0
```

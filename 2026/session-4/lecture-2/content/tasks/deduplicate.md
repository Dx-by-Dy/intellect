# Расписание без дублей

[Все задачи](../problems/index.md) · [Яндекс Контест · C](https://new.contest.yandex.ru/contests/104356/problems?id=7822306%2F2026_11_24%2FynnnEfQZVr){: target="_blank" rel="noopener" }

Ввод и вывод через стандартные потоки. Лимит времени — 1 с.

Сервис сравнения билетов получил список предложений для прямых рейсов. В списке могут быть разные цены для одного направления и несколько одинаковых записей. Пользователю достаточно показать самую низкую цену для каждого направления.

Рейс из города `u` в город `v` и рейс из `v` в `u` входят в разные направления. Составьте сводку из одного предложения на каждое направление, которое есть в списке.

## Входные данные

В первой строке даны целые числа `n` и `m` — число городов и рейсов (`1 ≤ n ≤ 100 000`, `0 ≤ m ≤ 200 000`).

В каждой из следующих `m` строк даны целые числа `u`, `v`, `w` — город вылета, город прилёта и цена (`1 ≤ u,v ≤ n`, `u ≠ v`, `0 ≤ w ≤ 10⁹`). Строки могут повторяться.

## Выходные данные

В первой строке выведите количество оставшихся направлений. Затем выведите по одной строке `u`, `v`, `w` для каждого направления, где `w` — минимальная цена рейса из `u` в `v`. Упорядочьте строки по возрастанию `u`, а при равном `u` — по возрастанию `v`.

## Примеры

### Пример 1

Ввод

```text
4 6
3 1 1
1 3 8
1 2 5
1 3 3
1 3 9
1 2 5
```

Вывод

```text
3
1 2 5
1 3 3
3 1 1
```

### Пример 2

Ввод

```text
1 0
```

Вывод

```text
0
```

# Несколько самых дешёвых маршрутов

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (CSES 1196)](https://cses.fi/problemset/task/1196){: target="_blank" rel="noopener" }

Лимит времени — 1 с, память — 512 МБ.

Найдите стоимости `k` самых дешёвых маршрутов из города `1` в город `n`. В одном маршруте можно несколько раз посетить один и тот же город. Разные маршруты с одинаковой стоимостью учитываются по отдельности. Гарантируется, что есть хотя бы `k` различных маршрутов.

## Входные данные

В первой строке записаны число городов `n`, число рейсов `m` и число искомых маршрутов `k` (`2 ≤ n ≤ 10⁵`, `1 ≤ m ≤ 2 · 10⁵`, `1 ≤ k ≤ 10`).

Далее идут `m` строк вида `a b c`. Каждая задаёт односторонний рейс из города `a` в город `b` стоимостью `c` (`1 ≤ a, b ≤ n`, `1 ≤ c ≤ 10⁹`).

## Выходные данные

Выведите `k` целых чисел — стоимости маршрутов в порядке неубывания.

## Пример

Ввод

```text
4 6 3
1 2 1
1 3 3
2 3 2
2 4 6
3 2 8
3 4 1
```

Вывод

```text
4 4 7
```

Маршруты `1 → 3 → 4` и `1 → 2 → 3 → 4` стоят по 4, а `1 → 2 → 4` стоит 7.

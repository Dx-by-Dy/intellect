# Скидка на рейс

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (CSES 1195)](https://cses.fi/problemset/task/1195){: target="_blank" rel="noopener" }

Лимит времени — 1 с, память — 512 МБ.

Нужно долететь из города `1` в город `n` как можно дешевле. На один рейс можно применить купон: его цена уменьшится вдвое с округлением вниз до целого. Купон можно использовать только один раз. Маршрут из города `1` в город `n` существует.

## Входные данные

Первая строка содержит число городов `n` и число рейсов `m` (`2 ≤ n ≤ 10⁵`, `1 ≤ m ≤ 2 · 10⁵`).

В каждой из следующих `m` строк заданы три числа `a b c`. Они описывают односторонний рейс из города `a` в город `b` за `c` (`1 ≤ a, b ≤ n`, `1 ≤ c ≤ 10⁹`).

## Выходные данные

Выведите одно целое число — минимальную стоимость поездки с учётом скидки.

## Пример

Ввод

```text
3 4
1 2 3
2 3 1
1 3 7
2 1 5
```

Вывод

```text
2
```

# Порядок фиксации

[Все задачи](../problems/index.md) · [Яндекс Контест · F](https://new.contest.yandex.ru/contests/104356/problems?id=7822306%2F2026_11_24%2FE5iolQ2KcN){: target="_blank" rel="noopener" }

Ввод и вывод через стандартные потоки. Лимит времени — 1 с.

Школьники сравнивают записи одной и той же трассировки Дейкстры. Чтобы порядок был однозначным, они договорились при равных текущих оценках выбирать вершину с меньшим номером.

Алгоритм запускают из вершины `s`. Её начальная оценка равна `0`, остальные оценки бесконечны. На каждом шаге выбирают ещё не зафиксированную вершину с наименьшей конечной оценкой, фиксируют её и обновляют оценки по исходящим дугам. Когда конечных оценок у незафиксированных вершин больше нет, алгоритм останавливается. Восстановите порядок фиксации.

## Входные данные

В первой строке даны целые числа `n`, `m`, `s` — число вершин, число дуг и номер начальной вершины (`1 ≤ n ≤ 100 000`, `0 ≤ m ≤ 200 000`, `1 ≤ s ≤ n`).

В каждой из следующих `m` строк даны целые числа `u`, `v`, `w` — дуга из `u` в `v` веса `w` (`1 ≤ u,v ≤ n`, `u ≠ v`, `0 ≤ w ≤ 10⁹`). Возможны параллельные дуги.

## Выходные данные

В первой строке выведите число зафиксированных вершин. Во второй строке выведите их номера в порядке фиксации.

## Примеры

### Пример 1

Ввод

```text
6 6 1
1 3 2
1 2 2
1 4 10
2 4 1
3 5 1
4 3 0
```

Вывод

```text
5
1 2 3 4 5
```

### Пример 2

Ввод

```text
4 3 4
4 3 0
3 1 0
4 2 0
```

Вывод

```text
4
4 2 3 1
```

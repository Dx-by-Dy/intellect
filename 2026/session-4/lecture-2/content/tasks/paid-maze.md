# Лабиринт с платными клетками

[Все задачи](../problems/index.md)

Ввод и вывод через стандартные потоки. Лимит времени — 1 с.

Участник квеста стоит в левой верхней клетке лабиринта. Выход расположен в правой нижней клетке. Некоторые клетки закрыты. За один шаг можно перейти в открытую клетку, у которой с текущей есть общая сторона.

В каждой открытой клетке указано, сколько времени занимает вход в неё. Это время прибавляется при каждом входе, в том числе в клетку с выходом. Отсчёт времени начинается, когда участник уже стоит в стартовой клетке. Найдите минимальное время до выхода.

## Входные данные

В первой строке даны целые числа `h` и `w` — число строк и столбцов (`1 ≤ h,w ≤ 500`).

В каждой из следующих `h` строк даны `w` целых чисел `a_{ij}` (`-1 ≤ a_{ij} ≤ 10⁹`). Число `-1` обозначает закрытую клетку, остальные числа обозначают время входа в клетку. Верхняя левая и нижняя правая клетки открыты.

## Выходные данные

Выведите одно целое число — наименьшее время пути. Если пройти нельзя, выведите `-1`.

## Примеры

### Пример 1

Ввод

```text
2 3
9 9 1
0 1 2
```

Вывод

```text
3
```

### Пример 2

Ввод

```text
2 2
0 -1
-1 1
```

Вывод

```text
-1
```

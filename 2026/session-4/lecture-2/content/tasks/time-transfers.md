# Быстрее, а при равенстве — меньше пересадок

[Все задачи](../problems/index.md) · [Яндекс Контест · G](https://new.contest.yandex.ru/contests/104356/problems?id=7822306%2F2026_11_24%2F5nSvDumUYx){: target="_blank" rel="noopener" }

Ввод и вывод через стандартные потоки. Лимит времени — 1 с.

Пассажир ищет самый быстрый маршрут из города `s` в город `t`. В расписании указано, сколько времени занимает каждый рейс. В городе пересадки можно сразу сесть на следующий рейс, поэтому время поездки равно сумме длительностей рейсов.

Если несколько маршрутов занимают одинаковое минимальное время, пассажир выбирает тот, в котором меньше пересадок. В поездке из `k` рейсов пересадок `k-1`. Найдите минимальное время и минимальное число пересадок среди поездок за это время.

## Входные данные

В первой строке даны целые числа `n`, `m`, `s`, `t` — число городов, число рейсов, город вылета и город назначения (`2 ≤ n ≤ 100 000`, `0 ≤ m ≤ 200 000`, `1 ≤ s,t ≤ n`, `s ≠ t`).

В каждой из следующих `m` строк даны целые числа `u`, `v`, `w` — рейс из `u` в `v` длительностью `w` минут (`1 ≤ u,v ≤ n`, `u ≠ v`, `0 ≤ w ≤ 10⁹`). Возможны несколько рейсов из одного города в другой.

## Выходные данные

Если маршрут существует, выведите в одной строке два целых числа — его минимальное время и наименьшее число пересадок среди маршрутов с этим временем. Если маршрута нет, выведите одно целое число `-1`.

## Примеры

### Пример 1

Ввод

```text
4 5 1 4
1 2 2
2 4 3
1 4 5
1 3 1
3 4 5
```

Вывод

```text
5 0
```

### Пример 2

Ввод

```text
3 3 1 3
1 3 5
1 2 0
2 3 3
```

Вывод

```text
3 1
```

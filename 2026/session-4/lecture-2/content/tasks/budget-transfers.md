# Билет по бюджету с пересадками

[Все задачи](../problems/index.md)

Ввод и вывод через стандартные потоки. Лимит времени — 1 с.

Пассажир выбирает, куда поехать из города `s`. Ему известны направления рейсов и цены билетов. У него есть `B` рублей на всю поездку, а в пути он готов сделать не более `K` пересадок. Подходят и прямые рейсы, и поездки с пересадками в пределах этого ограничения.

В поездке из `r` рейсов ровно `r-1` пересадок, а цена равна сумме цен всех билетов. Достаточно одного маршрута, чтобы город подошёл. Найдите все такие города, кроме города вылета.

## Входные данные

В первой строке даны целые числа `n`, `m`, `s`, `K`, `B` — число городов, число рейсов, город вылета, предел пересадок и бюджет (`1 ≤ n ≤ 80 000`, `0 ≤ m ≤ 160 000`, `1 ≤ s ≤ n`, `0 ≤ K ≤ 20`, `0 ≤ B ≤ 10¹⁵`).

В каждой из следующих `m` строк даны целые числа `u`, `v`, `w` — рейс из `u` в `v` за `w` рублей (`1 ≤ u,v ≤ n`, `u ≠ v`, `0 ≤ w ≤ 10⁹`). Возможны несколько рейсов из одного города в другой.

## Выходные данные

В первой строке выведите число подходящих городов. Если оно положительно, во второй строке выведите номера этих городов в порядке возрастания.

## Примеры

### Пример 1

Ввод

```text
5 4 1 1 5
1 2 2
2 3 3
3 4 0
1 5 6
```

Вывод

```text
2
2 3
```

### Пример 2

Ввод

```text
2 1 1 0 0
1 2 1
```

Вывод

```text
0
```

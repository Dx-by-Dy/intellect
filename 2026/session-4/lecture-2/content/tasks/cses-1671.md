# Кратчайшие маршруты I

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (CSES 1671)](https://cses.fi/problemset/task/1671){: target="_blank" rel="noopener" }

Лимит времени — 1 с, память — 512 МБ.

Города соединены односторонними рейсами. Для каждого города найдите длину кратчайшего маршрута из города `1`. Из него можно добраться до любого города.

## Входные данные

В первой строке указаны число городов `n` и число рейсов `m` (`1 ≤ n ≤ 10⁵`, `1 ≤ m ≤ 2 · 10⁵`).

Далее идут `m` строк по три числа `a b c`. Рейс из города `a` в город `b` имеет длину `c` (`1 ≤ a, b ≤ n`, `1 ≤ c ≤ 10⁹`).

## Выходные данные

Выведите `n` целых чисел. Число на позиции `i` равно длине кратчайшего маршрута из города `1` в город `i`.

## Пример

Ввод

```text
3 4
1 2 6
1 3 2
3 2 3
1 3 4
```

Вывод

```text
0 5 2
```

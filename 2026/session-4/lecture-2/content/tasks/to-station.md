# Все дороги к вокзалу

[Все задачи](../problems/index.md)

Ввод и вывод через стандартные потоки. Лимит времени — 1 с.

На вокзале в городе `t` будут встречать участников школьной смены. Участники выезжают из разных городов и хотят знать, сколько времени закладывать на дорогу до вокзала.

У каждой дороги есть направление и время проезда. Поездка может состоять из нескольких дорог, а её время равно сумме времён проезда. Для каждого города найдите минимальное время до вокзала. Тем, кто уже находится в городе `t`, ехать никуда не нужно.

## Входные данные

В первой строке даны целые числа `n`, `m`, `t` — число городов, число дорог и номер города с вокзалом (`1 ≤ n ≤ 100 000`, `0 ≤ m ≤ 200 000`, `1 ≤ t ≤ n`).

В каждой из следующих `m` строк даны целые числа `u`, `v`, `w` — дорога из `u` в `v` и время проезда по ней в минутах (`1 ≤ u,v ≤ n`, `u ≠ v`, `0 ≤ w ≤ 10⁹`). Возможны несколько дорог в одном направлении между двумя городами.

## Выходные данные

Выведите в одной строке `n` целых чисел в порядке номеров городов. Для города, из которого нельзя добраться до вокзала, выведите `-1`.

## Примеры

### Пример 1

Ввод

```text
5 5 3
1 3 10
1 2 1
2 3 2
3 4 1
4 1 20
```

Вывод

```text
3 2 0 23 -1
```

### Пример 2

Ввод

```text
2 1 1
1 2 0
```

Вывод

```text
0 -1
```

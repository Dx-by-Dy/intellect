# По пути за посылкой

[Все задачи](../problems/index.md)

Ввод и вывод через стандартные потоки. Лимит времени — 1 с.

Курьер выезжает из города `s` и должен доставить посылку в город `t`. Посылка ждёт его в пункте выдачи в городе `p`. Время поездки складывается из времени проезда по односторонним дорогам. Получение посылки занимает ноль минут.

Курьер может приезжать в один город несколько раз. Если он проедет через `t` до получения посылки, для завершения поездки ему нужно приехать туда с посылкой. Если пункт выдачи расположен на старте или финише, посылку можно забрать в начале или в конце поездки соответственно. Найдите наименьшее время поездки.

## Входные данные

В первой строке даны целые числа `n`, `m`, `s`, `p`, `t` — число городов, число дорог и номера городов старта, получения посылки и финиша (`1 ≤ n ≤ 100 000`, `0 ≤ m ≤ 200 000`, `1 ≤ s,p,t ≤ n`). Эти номера могут совпадать.

В каждой из следующих `m` строк даны целые числа `u`, `v`, `w` — дорога из `u` в `v` и время проезда в минутах (`1 ≤ u,v ≤ n`, `u ≠ v`, `0 ≤ w ≤ 10⁹`). Возможны несколько дорог в одном направлении между двумя городами.

## Выходные данные

Выведите одно целое число — наименьшее время поездки с посещением города `p`. Если такой поездки нет, выведите `-1`.

## Примеры

### Пример 1

Ввод

```text
4 5 1 3 4
1 4 0
1 2 1
2 3 2
1 3 5
3 4 6
```

Вывод

```text
9
```

### Пример 2

Ввод

```text
3 2 1 2 3
1 2 0
1 3 1
```

Вывод

```text
-1
```

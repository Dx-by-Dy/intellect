# Одна пересадка

[Все задачи](../problems/index.md)

Ввод и вывод через стандартные потоки. Лимит времени — 1 с.

Пассажир планирует поездку из города `s` в город `t`. По условиям поездки ему нужно сделать ровно одну пересадку. В расписании указаны направления рейсов и цены билетов. Первый рейс должен привести в промежуточный город, отличный от `s` и `t`, а второй — из этого города в `t`.

Стыковка возможна для любых двух рейсов с общим городом пересадки. Стоимость поездки равна сумме цен обоих билетов. Найдите минимальную стоимость такой поездки.

## Входные данные

В первой строке даны целые числа `n`, `m`, `s`, `t` — число городов, число рейсов, город отправления и город назначения (`2 ≤ n ≤ 100 000`, `0 ≤ m ≤ 200 000`, `1 ≤ s,t ≤ n`, `s ≠ t`).

В каждой из следующих `m` строк даны целые числа `u`, `v`, `w` — рейс из `u` в `v` за `w` рублей (`1 ≤ u,v ≤ n`, `u ≠ v`, `0 ≤ w ≤ 10⁹`). Возможны несколько рейсов из одного города в другой.

## Выходные данные

Выведите одно целое число — наименьшую стоимость поездки с одной пересадкой. Если такой поездки нет, выведите `-1`.

## Примеры

### Пример 1

Ввод

```text
4 6 1 4
1 4 0
1 2 9
1 2 3
2 4 5
1 3 2
3 4 9
```

Вывод

```text
8
```

### Пример 2

Ввод

```text
4 3 1 4
1 2 1
2 3 1
3 4 1
```

Вывод

```text
-1
```

# Ближайшая станция помощи

[Все задачи](../problems/index.md)

Ввод и вывод через стандартные потоки. Лимит времени — 1 с.

В одном или нескольких городах работают станции помощи. Житель любого города может выбрать любую из них. Между городами есть двусторонние дороги. Проезд по каждой дороге занимает одинаковое время в обоих направлениях.

Для каждого города найдите наименьшее время поездки до любой станции. Если в городе есть станция, время равно `0`. Из некоторых городов может оказаться невозможно доехать ни до одной станции.

## Входные данные

В первой строке даны целые числа `n`, `m`, `k` — число городов, дорог и станций (`1 ≤ k ≤ n ≤ 100 000`, `0 ≤ m ≤ 200 000`).

Во второй строке даны `k` различных целых чисел от `1` до `n` — номера городов, в которых есть станции.

В каждой из следующих `m` строк даны целые числа `u`, `v`, `w` — двусторонняя дорога между `u` и `v` и время проезда по ней в минутах (`1 ≤ u,v ≤ n`, `u ≠ v`, `0 ≤ w ≤ 10⁹`). Между двумя городами может быть несколько дорог.

## Выходные данные

Выведите в одной строке `n` целых чисел в порядке номеров городов. Для города, из которого нельзя добраться ни до одной станции, выведите `-1`.

## Примеры

### Пример 1

Ввод

```text
6 5 2
5 4
1 2 1
2 4 4
1 5 9
3 5 0
4 6 0
```

Вывод

```text
5 4 0 0 0 0
```

### Пример 2

Ввод

```text
3 0 1
2
```

Вывод

```text
-1 0 -1
```

# Билет по бюджету

[Все задачи](../problems/index.md) · [Яндекс Контест · A](https://new.contest.yandex.ru/contests/104356/problems?id=7822306%2F2026_11_24%2FjyxgvtLUjM){: target="_blank" rel="noopener" }

Ввод и вывод через стандартные потоки. Лимит времени — 1 с.

Маша планирует поездку на выходные. Она может вылететь из города `s` и готова потратить на билет до `B` рублей включительно. В расписании указан город отправления каждого рейса, город прибытия и цена билета.

Маша рассматривает только прямые рейсы. Из города `s` в один и тот же город может лететь несколько рейсов по разным ценам. Город подходит, если у Маши хватит денег хотя бы на один из них. Найдите все подходящие города.

## Входные данные

В первой строке даны целые числа `n`, `m`, `s`, `B` — число городов, число рейсов, город вылета и бюджет (`1 ≤ n ≤ 100 000`, `0 ≤ m ≤ 200 000`, `1 ≤ s ≤ n`, `0 ≤ B ≤ 10⁹`).

В каждой из следующих `m` строк даны целые числа `u`, `v`, `w` — рейс из `u` в `v` за `w` рублей (`1 ≤ u,v ≤ n`, `u ≠ v`, `0 ≤ w ≤ 10⁹`). Из одного города в другой может лететь несколько рейсов.

## Выходные данные

В первой строке выведите количество подходящих городов. Если оно больше нуля, во второй строке выведите номера этих городов по возрастанию.

## Примеры

### Пример 1

Ввод

```text
5 7 3 8
3 5 8
3 5 7
3 1 1
3 1 8
3 2 9
2 3 0
1 4 0
```

Вывод

```text
2
1 5
```

### Пример 2

Ввод

```text
2 2 1 0
1 2 1
2 1 0
```

Вывод

```text
0
```

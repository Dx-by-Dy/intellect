# Задачи для практики

Задачи разбиты на 4 уровня.

[Задачи в Яндекс Контесте](https://new.contest.yandex.ru/contests/104356/problems){: target="_blank" rel="noopener" }

Откройте название задачи, чтобы прочитать условие. Буква ведёт к задаче в Яндекс Контесте. Номер задачи ACMP или CSES ведёт на исходное условие и страницу отправки решений.

Застряли надолго — спросите преподавателя, он подскажет, куда смотреть.

## С чего начать

| Если вы | Маршрут |
|---|---|
| впервые решаете задачи на взвешенные графы | уровень 1, затем [ACMP 132](https://acmp.ru/index.asp?main=task&id_task=132){: target="_blank" rel="noopener" } |
| уверенно пишете программы, но только познакомились с Дейкстрой | [ACMP 132](https://acmp.ru/index.asp?main=task&id_task=132){: target="_blank" rel="noopener" } → [ACMP 1381](https://acmp.ru/asp/do/index.asp?id_course=2&id_problem=1037&id_section=32&id_topic=54&main=task){: target="_blank" rel="noopener" } → [CSES 1671](https://cses.fi/problemset/task/1671){: target="_blank" rel="noopener" } |
| уже умеете писать Дейкстру | уровень 3, затем уровень 4 |
| занимаетесь олимпиадами и знакомы с кратчайшими путями | сразу уровень 4 |

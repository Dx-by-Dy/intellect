# Графы: хранение в памяти, DFS и BFS

Занятие из трёх частей: лекция, практика и разбор задач.

| Часть | Что делаем | Материал |
|---|---|---|
| 1 | Лекция | интерактивная страница: https://dx-by-dy.github.io/intellect/2026/session-4/lecture-1/ |
| 2 | Решаем задачи | [`problems.md`](problems.md), тот же список есть на странице лекции в разделе «Задачи» |
| 3 | Разбор задач | [`answers/README.md`](answers/README.md), решения в [`answers/solutions/`](answers/solutions/) |

## Перед занятием

Зарегистрируйтесь на [informatics.msk.ru](https://informatics.msk.ru): без этого не получится отправлять решения. Если вы уже уверенно решаете задачи, зарегистрируйтесь ещё на [CSES](https://cses.fi/problemset/) и [Codeforces](https://codeforces.com).

## Страница лекции

Страница идёт сверху вниз: что такое граф, как его хранить, DFS, BFS, обход клетчатого поля, сравнение DFS и BFS, задачи. Демонстрации работают прямо на странице: кликайте по вершинам, клеткам матрицы и кнопкам шагов. Если кликнуть по анимации, шаги можно листать клавишами ← и →.

## Решения

Каждое решение в [`answers/solutions/`](answers/solutions/) — полная программа на C++17. Сначала попробуйте решить задачу сами и только потом открывайте решение.

Проверить решения на тестах:

```bash
cd answers
./run_tests.sh
```

Нужны `g++` с поддержкой C++17 и `python3`.

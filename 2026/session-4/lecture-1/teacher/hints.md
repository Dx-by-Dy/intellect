# Подсказки к задачам практики (пара 2)

Список задач для учеников — [`../problems.md`](../problems.md). Здесь то же самое с подсказками. Давайте их по одной, начиная с самой общей, и только если ученик застрял.

## Маршруты

| Кто | Маршрут |
|---|---|
| Видят графы впервые, C++ знают слабо | 462 → 464 → 465 → 470 → 164 → 160 → 111540 |
| Уверенно пишут циклы и массивы | 464 → 164 → 111540 → 160 → 161 → 165 → CSES 1192 |
| Олимпиадники | сразу уровень 3, потом 4 |

- Всем, кто видит графы впервые, начать с inf 462 и inf 464 (5–10 минут): так проверяется, что чтение ввода работает.
- Цель для среднего ученика за пару: 164, 111540, 160, 161.
- Сильным сразу уровень 3, в конце уровень 4. Если сильный ученик всё решил, дайте ему CF 1520G или CSES 1194 Monsters.

## Уровень 1. Хранение графа

Задачи проверяют, что ученик понимает, что такое матрица смежности и список рёбер, и умеет их читать.

| Задача | Подсказка |
|---|---|
| inf 462 Подсчет количества ребер | Каждое ребро записано в матрице дважды. Ответ: сумма всех элементов / 2. |
| inf 464 От матрицы смежности к списку ребер | Выводите только пары с `i < j`, иначе каждое ребро напечатается дважды. |
| inf 465 От списка ребер к матрице смежности | Для ребра `u v` ставим `a[u][v] = a[v][u] = 1`. |
| inf 470 Степени вершин | Степень вершины `i` — сумма строки `i`. Выводить по одному числу в строке. |
| inf 175 Светофорчики | Матрица не нужна: для ребра `u v` делаем `deg[u]++, deg[v]++`. |
| inf 474 Истоки и стоки | Исток: столбец из нулей (никто не входит). Сток: строка из нулей. |
| inf 460 Проверка на неориентированность | Матрица должна быть симметричной, а на диагонали должны стоять нули (нет петель). |

## Уровень 2. Базовые обходы

| Задача | Подсказка |
|---|---|
| inf 164 Обход в глубину | Запустить DFS из `S` и посчитать посещённые вершины. |
| inf 111540 Компоненты связности | `n` до 10⁵: только списки смежности. Каждый запуск DFS из непосещённой вершины — новая компонента, собираем её вершины в `vector`. |
| inf 160 Путь | Массив `par`, идём от финиша назад и разворачиваем. Если старт = финиш, вывести только `0`. Нет пути — `-1`. |
| inf 161 Один конь | Вершина — клетка, 8 ходов через массивы `dx`, `dy`. Путь восстанавливаем как в «Путь», `par` хранит пару координат. |
| inf 111541 Баобаб | Дерево = связный граф, в котором ровно `n − 1` ребро. Связность проверяем DFS. |
| CSES 1192 Counting Rooms | Считаем компоненты из клеток `.`. Поле до 1000×1000, глубокая рекурсия может упасть, надёжнее BFS. |
| CSES 1666 Building Roads | Нужно `k − 1` дорог, где `k` — число компонент. Соединяем «представителя» первой компоненты с представителями остальных. |
| CSES 1667 Message Route | Как «Путь», но `n` до 10⁵. Выводится число вершин пути, а не рёбер. Нет пути — `IMPOSSIBLE`. |
| CF 115A Party | Начальники образуют лес. Ответ — число вершин в самой длинной цепочке «начальник → подчинённый». |

## Уровень 3. Применения обходов

| Задача | Подсказка |
|---|---|
| inf 165 Банкет | Красим DFS в цвета 1 и 2, соседи — в разные. Конфликт → `NO`. Не забыть про несвязный граф. |
| CSES 1668 Building Teams | То же, что «Банкет», вывести цвет каждой вершины. |
| inf 162 Табличка | Положить в очередь **все** клетки с единицей с `d = 0` и запустить один BFS. BFS из каждой клетки отдельно не пройдёт по времени. |
| inf 163 Два коня | Вершина графа — пара позиций (конь 1, конь 2), всего 64·64 состояния. За один ход оба коня делают по ходу. Ищем ближайшее состояние, где позиции совпали. |
| CSES 1193 Labyrinth | В `par` храним, каким ходом (`L`, `R`, `U`, `D`) пришли в клетку. Путь собираем с конца и разворачиваем. |
| CSES 1669 Round Trip | DFS с запоминанием родителя. Ребро в посещённую вершину, не родителя — цикл. Сам цикл восстанавливаем по `par`. |
| CF 893C Rumor | В каждой компоненте подкупаем самого дешёвого. Ответ в `long long`. |
| CF 862B Mahmoud and Ehab and the bipartiteness | Покрасить дерево в 2 цвета, размеры долей `a` и `b`. Ответ `a·b − (n − 1)`, в `long long`. |
| CF 520B Two Buttons | Вершины — числа от 1 до 2·10⁴, рёбра `x → 2x` и `x → x − 1`. BFS от `n` до `m`. |
| CF 977E Cyclic Components | Компонента — цикл, если у всех её вершин степень ровно 2. |
| CF 580C Kefa and Park | Передаём в DFS число котов подряд на текущем пути. Если стало больше `m` — дальше не идём. Считаем дошедшие листья. |

## Уровень 4. Со звёздочкой

| Задача | Подсказка |
|---|---|
| inf 166 Построение | DFS с тремя цветами. Ребро в «серую» вершину — цикл, ответ `No`. Иначе порядок выхода из вершин, развёрнутый. |
| CSES 1679 Course Schedule | То же на `n` до 10⁵. Удобнее алгоритм Кана: очередь из вершин с нулевой входящей степенью. |
| CSES 1194 Monsters | Сначала многоисточниковый BFS от всех монстров: когда монстр может оказаться в клетке. Потом BFS от `A` только по клеткам, куда успеваем строго раньше монстров. Нужно дойти до края. |
| CF 377A Maze | Обходим DFS из любой свободной клетки. Первые `s − k` посещённых клеток оставляем, остальные свободные превращаем в `X`: связность сохраняется. |
| CF 1006E Military Problem | DFS выписывает вершины в порядке входа (`tin[v]`), запоминаем размер поддерева. Ответ — `order[tin[u] + k − 1]`, если `k ≤ size[u]`. Детей обходить по возрастанию номеров. |
| CF 1037D Valid BFS? | Отсортировать соседей каждой вершины по позиции в данной последовательности, запустить BFS и сравнить порядок. |
| CF 1365D Solve The Maze | Обнести каждого плохого стенами со всех сторон (если рядом хороший — сразу `No`). Потом BFS от выхода: все хорошие должны быть достижимы. |
| CF 1093D Beautiful Graph | Каждая компонента должна быть двудольной с долями `a` и `b`. Её вклад `2^a + 2^b`, ответ — произведение по модулю 998244353. |
| CF 1272E Nearest Opposite Parity | Развернуть рёбра. BFS из всех нечётных вершин сразу даёт ответ для чётных, и наоборот. |
| CF 1520G To Go Or Not To Go? | BFS от старта и от финиша. Ответ — минимум из «дойти пешком» и «лучший портал рядом со стартом + лучший портал рядом с финишем». Всё в `long long`. |

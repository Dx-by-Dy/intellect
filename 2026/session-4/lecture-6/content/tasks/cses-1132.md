# Самые далёкие вершины

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (CSES 1132)](https://cses.fi/problemset/task/1132/){: target="_blank" rel="noopener" }

Лимит времени — 1 с, память — 512 МБ.

Для каждой вершины дерева найдите максимальное расстояние от неё до вершины дерева. Расстояние равно числу рёбер на пути. Если вершина всего одна, её ответ равен нулю.

## Входные данные

Первая строка содержит `n` (`1 ≤ n ≤ 2 · 10⁵`). Вершины пронумерованы от `1` до `n`.

Каждая из следующих `n − 1` строк содержит пару концов ребра `a b` (`1 ≤ a, b ≤ n`).

## Выходные данные

Выведите `n` целых чисел по порядку номеров вершин.

## Пример

Ввод

```text
5
1 2
1 3
3 4
3 5
```

Вывод

```text
2 3 2 3 3
```

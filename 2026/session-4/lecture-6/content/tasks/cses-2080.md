# Пути заданной длины I

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (CSES 2080)](https://cses.fi/problemset/task/2080/){: target="_blank" rel="noopener" }

Лимит времени — 1 с, память — 512 МБ.

Посчитайте, сколько в дереве простых путей длины ровно `k` рёбер. Путь и тот же путь в обратном направлении считаются один раз.

## Входные данные

В первой строке указаны `n k` (`1 ≤ k ≤ n ≤ 2 · 10⁵`), где `n` — число вершин. Вершины пронумерованы от `1` до `n`.

Следующие `n − 1` строк задают рёбра парами номеров `a b` (`1 ≤ a, b ≤ n`).

## Выходные данные

Выведите одно целое число — количество путей длины `k`.

## Пример

Ввод

```text
5 2
1 2
2 3
3 4
3 5
```

Вывод

```text
4
```

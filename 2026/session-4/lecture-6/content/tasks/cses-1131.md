# Диаметр дерева

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (CSES 1131)](https://cses.fi/problemset/task/1131/){: target="_blank" rel="noopener" }

Лимит времени — 1 с, память — 512 МБ.

Дано дерево. Расстояние между двумя вершинами равно числу рёбер на соединяющем их пути. Найдите диаметр дерева — наибольшее такое расстояние.

## Входные данные

В первой строке записано `n` (`1 ≤ n ≤ 2 · 10⁵`). Вершины пронумерованы от `1` до `n`.

Следующие `n − 1` строк содержат по два числа `a b` (`1 ≤ a, b ≤ n`), которые задают концы ребра.

## Выходные данные

Выведите одно целое число — диаметр дерева в рёбрах.

## Пример

Ввод

```text
5
1 2
1 3
3 4
3 5
```

Вывод

```text
3
```

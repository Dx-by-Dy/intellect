# Поиск центроида

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (CSES 2079)](https://cses.fi/problemset/task/2079/){: target="_blank" rel="noopener" }

Лимит времени — 1 с, память — 512 МБ.

Найдите центроид дерева из `n` вершин. Если удалить центроид вместе со всеми рёбрами, которые к нему примыкают, каждая оставшаяся компонента будет содержать не больше `⌊n/2⌋` вершин.

## Входные данные

В первой строке дано `n` (`1 ≤ n ≤ 2 · 10⁵`). Вершины пронумерованы от `1` до `n`.

Затем идут `n − 1` строк с парами `a b` (`1 ≤ a, b ≤ n`). Каждая пара задаёт одно ребро.

## Выходные данные

Выведите номер любого центроида. Если таких вершин несколько, достаточно одной.

## Пример

Ввод

```text
5
1 2
2 3
3 4
3 5
```

Вывод

```text
3
```

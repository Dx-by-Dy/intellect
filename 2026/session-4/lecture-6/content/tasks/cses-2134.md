# Запросы на путях II

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (CSES 2134)](https://cses.fi/problemset/task/2134/){: target="_blank" rel="noopener" }

Лимит времени — 1 с, память — 512 МБ.

В каждой вершине дерева записано число. Обрабатывайте запросы по порядку. Запрос может заменить число в одной вершине или потребовать наибольшее число среди вершин пути между двумя заданными вершинами. Оба конца входят в путь.

## Входные данные

В первой строке даны числа вершин и запросов `n q` (`1 ≤ n, q ≤ 2 · 10⁵`). Вершины имеют номера от `1` до `n`.

Следующая строка содержит начальные значения `v₁, …, vₙ` (`1 ≤ vᵢ ≤ 10⁹`). Затем идут `n − 1` строк с парами концов рёбер `a b` (`1 ≤ a, b ≤ n`).

Последние `q` строк задают запросы. В запросе `1 s x` замените значение вершины `s` на `x` (`1 ≤ s ≤ n`, `1 ≤ x ≤ 10⁹`). Запрос `2 a b` спрашивает максимум на пути из `a` в `b` (`1 ≤ a, b ≤ n`).

## Выходные данные

Выведите ответы на запросы второго типа в порядке их поступления.

## Пример

Ввод

```text
5 3
2 4 1 3 3
1 2
1 3
2 4
2 5
2 3 5
1 2 2
2 3 5
```

Вывод

```text
4 3
```

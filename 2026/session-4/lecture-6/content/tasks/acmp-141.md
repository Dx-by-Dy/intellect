# Дерево

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (ACMP 141)](https://acmp.ru/index.asp?main=task&id_task=141){: target="_blank" rel="noopener" }

Лимит времени — 1 с, память — 16 МБ.

Дан неориентированный граф. В нём нет петель и кратных рёбер. Определите, является ли он деревом.

## Входные данные

В `INPUT.TXT` записано число вершин `N` (`1 ≤ N ≤ 100`), за ним — симметричная матрица смежности размера `N × N`. Единица в ячейке означает наличие ребра между соответствующими вершинами, ноль — его отсутствие.

## Выходные данные

Запишите в `OUTPUT.TXT` слово `YES` для дерева и `NO` в остальных случаях.

## Пример

Ввод

```text
3
0 1 0
1 0 1
0 1 0
```

Вывод

```text
YES
```

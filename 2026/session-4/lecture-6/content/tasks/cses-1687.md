# Запросы о начальниках I

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (CSES 1687)](https://cses.fi/problemset/task/1687/){: target="_blank" rel="noopener" }

Лимит времени — 1 с, память — 512 МБ.

Сотрудники компании образуют иерархию. У каждого сотрудника, кроме генерального директора, есть непосредственный начальник. Для каждого запроса найдите начальника сотрудника `x` на `k` уровней выше.

## Входные данные

В первой строке заданы числа сотрудников и запросов `n q` (`1 ≤ n, q ≤ 2 · 10⁵`). Сотрудники имеют номера от `1` до `n`, генеральный директор — номер `1`.

Во второй строке перечислены `e₂, e₃, …, eₙ`. Число `eᵢ` обозначает прямого начальника сотрудника `i`, причём `1 ≤ eᵢ ≤ i − 1`.

Затем идут `q` строк вида `x k` (`1 ≤ x ≤ n`, `1 ≤ k ≤ n`).

## Выходные данные

Для каждого запроса выведите номер начальника сотрудника `x` на `k` уровней выше. Если такого начальника нет, выведите `-1`.

## Пример

Ввод

```text
5 3
1 1 3 3
4 1
4 2
4 3
```

Вывод

```text
3
1
-1
```

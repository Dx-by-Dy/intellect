# Центр звезды

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (LeetCode 1791)](https://leetcode.com/problems/find-center-of-star-graph/){: target="_blank" rel="noopener" }

Числовые лимиты времени и памяти в открытом условии LeetCode не указаны. Для сдачи реализуйте метод класса `Solution`.

Дан неориентированный граф-звезда. В нём есть одна центральная вершина, от которой проведены рёбра ко всем остальным вершинам. Найдите её номер.

## Входные данные

```cpp
int findCenter(vector<vector<int>>& edges)
```

Метод получает массив `edges` из `n − 1` пар `[u, v]`. Вершины имеют номера от `1` до `n`, где `3 ≤ n ≤ 10⁵`. В каждой паре `1 ≤ u, v ≤ n` и `u ≠ v`. Рёбра гарантированно образуют звезду.

## Выходные данные

Верните номер центральной вершины.

## Пример 1

Аргументы

```text
edges = [[1,2],[2,3],[4,2]]
```

Возвращаемое значение

```text
2
```

## Пример 2

Аргументы

```text
edges = [[1,2],[5,1],[1,3],[1,4]]
```

Возвращаемое значение

```text
1
```

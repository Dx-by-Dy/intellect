# Грабитель домов III

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (LeetCode 337)](https://leetcode.com/problems/house-robber-iii/){: target="_blank" rel="noopener" }

Числовые лимиты времени и памяти в открытом условии LeetCode не указаны. Для сдачи реализуйте метод класса `Solution`.

Дома образуют двоичное дерево. В каждом доме есть определённая сумма денег. Сигнализация срабатывает, если за одну ночь ограбить два дома, соединённых ребром. Найдите наибольшую сумму, которую можно получить без срабатывания сигнализации.

## Входные данные

```cpp
int rob(TreeNode* root)
```

Метод получает указатель `root` на корень. У узла `TreeNode` есть значение `val` и указатели на левого и правого ребёнка `left` и `right`.

В дереве от `1` до `10⁴` узлов. Значение каждого узла лежит в диапазоне `0 ≤ Node.val ≤ 10⁴`. В примерах дерево записано по уровням. `null` обозначает отсутствующего ребёнка.

## Выходные данные

Верните наибольшую сумму значений выбранных узлов, среди которых нет двух соседних.

## Пример 1

Аргументы

```text
root = [3,2,3,null,3,null,1]
```

Возвращаемое значение

```text
7
```

## Пример 2

Аргументы

```text
root = [3,4,5,1,3,null,1]
```

Возвращаемое значение

```text
9
```

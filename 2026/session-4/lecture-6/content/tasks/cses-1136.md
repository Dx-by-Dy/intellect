# Подсчёт путей

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (CSES 1136)](https://cses.fi/problemset/task/1136/){: target="_blank" rel="noopener" }

Лимит времени — 1 с, память — 512 МБ.

Дано дерево и список путей, каждый из которых задан своими концами. Для каждой вершины посчитайте, сколько путей из списка содержат эту вершину. Концы пути тоже считаются его вершинами.

## Входные данные

В первой строке записаны числа вершин и путей `n m` (`1 ≤ n, m ≤ 2 · 10⁵`). Вершины пронумерованы от `1` до `n`.

Следующие `n − 1` строк содержат по два номера вершин — концы рёбер. Затем идут `m` строк с парами концов заданных путей. Все номера лежат в диапазоне от `1` до `n`.

## Выходные данные

Выведите `n` целых чисел. На позиции `i` запишите число заданных путей, содержащих вершину `i`.

## Пример

Ввод

```text
5 3
1 2
1 3
3 4
3 5
1 3
2 5
1 4
```

Вывод

```text
3 1 3 1 1
```

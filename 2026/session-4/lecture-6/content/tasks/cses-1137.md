# Запросы на поддеревьях

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (CSES 1137)](https://cses.fi/problemset/task/1137/){: target="_blank" rel="noopener" }

Лимит времени — 1 с, память — 512 МБ.

Дано корневое дерево. В каждой вершине записано число. Обрабатывайте запросы по порядку. Одни заменяют число в указанной вершине, другие спрашивают сумму по её поддереву, включая саму вершину.

## Входные данные

В первой строке заданы числа вершин и запросов `n q` (`1 ≤ n, q ≤ 2 · 10⁵`). Вершины пронумерованы от `1` до `n`, корень — вершина `1`.

Во второй строке записаны значения вершин `v₁, …, vₙ` (`1 ≤ vᵢ ≤ 10⁹`). Следующие `n − 1` строк содержат пары `a b` (`1 ≤ a, b ≤ n`), задающие рёбра.

Затем идут `q` запросов. Запрос `1 s x` присваивает вершине `s` значение `x` (`1 ≤ s ≤ n`, `1 ≤ x ≤ 10⁹`). Запрос `2 s` требует сумму в поддереве вершины `s` (`1 ≤ s ≤ n`).

## Выходные данные

Выведите ответы на запросы второго типа в том же порядке, в котором они поступили.

## Пример

Ввод

```text
5 3
4 2 5 2 1
1 2
1 3
3 4
3 5
2 3
1 5 3
2 3
```

Вывод

```text
8
10
```

# Подчинённые

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (CSES 1674)](https://cses.fi/problemset/task/1674/){: target="_blank" rel="noopener" }

Лимит времени — 1 с, память — 512 МБ.

В компании `n` сотрудников. Каждый, кроме генерального директора, подчиняется одному непосредственному начальнику. Для каждого сотрудника посчитайте, сколько людей находятся ниже него в иерархии на любом уровне.

## Входные данные

В первой строке указано `n` (`1 ≤ n ≤ 2 · 10⁵`). Сотрудники пронумерованы от `1` до `n`, генеральный директор имеет номер `1`.

Далее идут `n − 1` чисел. Они задают номера непосредственных начальников сотрудников `2, 3, …, n` в этом порядке.

## Выходные данные

Выведите `n` целых чисел по порядку номеров сотрудников. Число на позиции `i` — количество прямых и непрямых подчинённых сотрудника `i`.

## Пример

Ввод

```text
5
1 1 2 3
```

Вывод

```text
4 1 1 0 0
```

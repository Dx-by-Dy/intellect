# Прямой обход дерева

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (LeetCode 589)](https://leetcode.com/problems/n-ary-tree-preorder-traversal/){: target="_blank" rel="noopener" }

Числовые лимиты времени и памяти в открытом условии LeetCode не указаны. Для сдачи реализуйте метод класса `Solution`.

Дано корневое дерево, в котором у каждой вершины может быть произвольное число детей. Выпишите значения в порядке прямого обхода. Сначала идёт значение самой вершины, затем обходы её детей в заданном порядке.

## Входные данные

```cpp
vector<int> preorder(Node* root)
```

Метод получает указатель `root` на корень или `nullptr` для пустого дерева. У узла `Node` есть значение `val` и упорядоченный список детей `children`.

В дереве от `0` до `10⁴` узлов, `0 ≤ Node.val ≤ 10⁴`. Высота дерева не превышает `1000`. В примерах LeetCode записывает дерево по уровням, отделяя списки детей разных узлов маркером `null`.

## Выходные данные

Верните одномерный массив значений в порядке обхода. Для пустого дерева верните пустой массив.

## Пример 1

Аргументы

```text
root = [1,null,3,2,4,null,5,6]
```

Возвращаемое значение

```text
[1,3,5,6,2,4]
```

## Пример 2

Аргументы

```text
root = [1,null,2,3,4,5,null,null,6,7,null,8,null,9,10,null,null,11,null,12,null,13,null,null,14]
```

Возвращаемое значение

```text
[1,2,3,6,7,11,14,4,8,12,5,9,13,10]
```

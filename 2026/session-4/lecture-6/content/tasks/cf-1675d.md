# Вертикальные пути

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (CF 1675D)](https://codeforces.com/problemset/problem/1675/D?locale=ru){: target="_blank" rel="noopener" }

Лимит времени — 2 с, память — 256 МБ.

Дано корневое дерево. Разбейте все его вершины на пути. От каждой вершины в таком пути можно перейти только к одному из её детей. Путь может состоять из одной вершины. Каждая вершина должна попасть ровно в один путь, а число путей должно быть минимальным.

## Входные данные

В первой строке записано число наборов `t` (`1 ≤ t ≤ 10⁴`).

В каждом наборе сначала дано число вершин `n` (`1 ≤ n ≤ 2 · 10⁵`), затем `n` чисел `p₁, …, pₙ` (`1 ≤ pᵢ ≤ n`). Число `pᵢ` обозначает родителя вершины `i`. У корня `pᵢ = i`. Только корень имеет это свойство, и его номер может быть любым. Массив родителей гарантированно задаёт дерево.

Сумма `n` по всем наборам не превышает `2 · 10⁵`.

## Выходные данные

Для каждого набора выведите минимальное число путей `m`. Затем для каждого пути выведите две строки. В первой запишите число вершин пути, во второй — их номера сверху вниз.

Можно вывести пути в любом порядке. При нескольких оптимальных разбиениях подойдёт любое. Ниже два набора из исходного примера.

## Пример

Ввод

```text
2
5
3 1 3 3 1
1
1
```

Вывод

```text
3
3
3 1 5
1
2
1
4
1
1
1
```

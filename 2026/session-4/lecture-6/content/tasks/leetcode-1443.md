# Собрать все яблоки

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (LeetCode 1443)](https://leetcode.com/problems/minimum-time-to-collect-all-apples-in-a-tree/){: target="_blank" rel="noopener" }

Числовые лимиты времени и памяти в открытом условии LeetCode не указаны. Для сдачи реализуйте метод класса `Solution`.

В некоторых вершинах дерева лежат яблоки. Переход по одному ребру занимает секунду. Найдите минимальное время, за которое можно начать в вершине `0`, собрать все яблоки и вернуться в `0`.

## Входные данные

```cpp
int minTime(int n, vector<vector<int>>& edges, vector<bool>& hasApple)
```

У метода три аргумента.

- `n` — число вершин (`1 ≤ n ≤ 10⁵`), пронумерованных от `0` до `n − 1`.
- `edges` — массив из `n − 1` пар `[a, b]`, где `0 ≤ a < b ≤ n − 1`. Пары задают рёбра неориентированного дерева.
- `hasApple` — массив из `n` логических значений. `hasApple[i] = true` означает, что в вершине `i` есть яблоко.

## Выходные данные

Верните минимальное время в секундах. Если идти никуда не требуется, верните `0`.

## Пример 1

Аргументы

```text
n = 7
edges = [[0,1],[0,2],[1,4],[1,5],[2,3],[2,6]]
hasApple = [false,false,true,false,true,true,false]
```

Возвращаемое значение

```text
8
```

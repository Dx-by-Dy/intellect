# Ксюша и дерево

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (CF 342E)](https://codeforces.com/problemset/problem/342/E?locale=ru){: target="_blank" rel="noopener" }

Лимит времени — 5 с, память — 256 МБ.

Дано дерево. Сначала вершина `1` красная, а остальные синие. По запросам перекрашивайте синие вершины в красный цвет и находите расстояние от заданной вершины до ближайшей красной. Расстояние измеряется числом рёбер.

## Входные данные

В первой строке даны числа вершин и запросов `n m` (`2 ≤ n ≤ 10⁵`, `1 ≤ m ≤ 10⁵`).

Следующие `n − 1` строк задают рёбра парами `aᵢ bᵢ` (`1 ≤ aᵢ, bᵢ ≤ n`, `aᵢ ≠ bᵢ`). Рёбра гарантированно образуют дерево.

Далее идёт `m` строк вида `tᵢ vᵢ` (`1 ≤ tᵢ ≤ 2`, `1 ≤ vᵢ ≤ n`). Запрос `1 vᵢ` красит синюю вершину `vᵢ` в красный. Запрос `2 vᵢ` спрашивает расстояние от `vᵢ` до ближайшей красной вершины. Все запросы корректны.

## Выходные данные

Для каждого запроса второго типа выведите одно расстояние в отдельной строке.

## Пример

Ввод

```text
5 4
1 2
2 3
2 4
4 5
2 1
2 5
1 2
2 5
```

Вывод

```text
0
3
2
```

# Подмножество максимального веса

[Все задачи](../problems/index.md) · [Оригинал и отправка решения (CF 1249F)](https://codeforces.com/problemset/problem/1249/F?locale=ru){: target="_blank" rel="noopener" }

Лимит времени — 2 с, память — 256 МБ.

Каждая вершина дерева имеет вес. Выберите подмножество вершин с наибольшим суммарным весом. Для любой пары различных выбранных вершин число рёбер на пути между ними должно быть строго больше `k`.

## Входные данные

В первой строке даны `n k` (`1 ≤ n, k ≤ 200`), где `n` — число вершин. Во второй строке записаны веса `a₁, …, aₙ` (`1 ≤ aᵢ ≤ 10⁵`).

В следующих `n − 1` строках идут рёбра. Каждое ребро задано парой различных номеров `u v` (`1 ≤ u, v ≤ n`). Все рёбра образуют дерево.

## Выходные данные

Выведите наибольший суммарный вес допустимого подмножества.

## Пример 1

Ввод

```text
5 1
1 2 3 4 5
1 2
2 3
3 4
3 5
```

Вывод

```text
11
```

## Пример 2

Ввод

```text
7 2
2 1 2 1 2 1 1
6 4
1 5
3 1
2 3
7 5
7 4
```

Вывод

```text
4
```

# Смена 3: «Структуры данных изнутри»

Курс по внутреннему устройству структур данных на языке C: от чисел, строк и списков до хеш-таблиц. Материалы этой смены ведутся в отдельных репозиториях:

| Репозиторий | Для кого | Что в нём |
|---|---|---|
| [data-structures-inside](https://github.com/Dx-by-Dy/data-structures-inside) | ученики | лекции, задачи, инструкция подключения к учебной машине, правила защиты |
| [C-base](https://github.com/Dx-by-Dy/C-base) | преподаватель (приватный) | исходники лекций, методичка, учебная машина; отсюда материалы копируются в ученический репозиторий |

## Как добавить свои материалы

Каждое занятие лежит в своей папке `<год>/session-<смена>/lecture-<занятие>/`. Что и как внутри неё устроено, решает автор, но для публикации есть общие правила.

### Публикация страницы

- **Всё, что лежит в папке `docs/` с файлом `index.html`, публикуется автоматически.** Папка `<путь>/docs/` после push в `main` открывается по адресу `https://dx-by-dy.github.io/intellect/<путь>/` и попадает в общий список страниц. Workflow для этого менять не нужно.
- В `docs/` кладите только готовую страницу для учеников: собранный HTML, стили, картинки. Не кладите туда черновики, решения и заметки для преподавателя, а если нужна другая документация, назовите папку иначе. Учтите, что сам репозиторий публичный, и ученики видят всё, что в нём лежит, а не только `docs/`.
- **Ссылки только относительные:** `style.css`, `img/graph.png`, `../lecture-2/`. Сайт живёт не в корне домена, а в `/intellect/<путь>/`, поэтому ссылка вида `/style.css` поведёт не туда.
- Файлы в UTF-8.
- Не кладите в `docs/` тяжёлые файлы (видео, архивы): лимит на весь сайт — 1 ГБ. Видео лучше выложить отдельно и дать ссылку.
- Папка `docs/` в корне репозитория и папки, имя которых начинается с `.` или `_`, не публикуются.

### Если страница не появилась

Откройте вкладку Actions → последний запуск Deploy Pages. Проблемы конкретной страницы показываются там предупреждениями и ошибками с путём к файлу, а остальные страницы при этом всё равно публикуются.

- `page ... skipped: ... collides with page ...` — файлы двух страниц попадают по одному адресу. Обычно так бывает, когда в `a/docs/` есть подпапка `b/`, и при этом существует `a/b/docs/`. Переименуйте одну из папок.
- `page ... skipped: not a regular file` — в `docs/` лежит битая символическая ссылка или не обычный файл.
- `root-absolute link` — в странице есть ссылка, начинающаяся с `/`. Страница опубликована, но эта ссылка не откроется.
- `not valid UTF-8` — страница опубликована, но русский текст может отображаться неправильно.

Проверить сборку сайта до push:

```bash
python3 scripts/build_pages.py   # сайт собирается в _site/ (он в .gitignore)
```

Скрипт и `.github/workflows/pages.yml` общие для всех страниц. Не меняйте их, не договорившись с владельцем репозитория.
